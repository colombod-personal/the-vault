Support

Get help or report a problem

Open an issue on the project's public GitHub issues page (see existing ones). A free GitHub account is needed. Please do not put your collection, tokens or other private data in an issue.

The Vault is a free hobby project run in spare time. Help is best effort: there is no guaranteed response time, and most reports get a first reply within a few days.
